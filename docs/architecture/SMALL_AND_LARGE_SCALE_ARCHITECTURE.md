# Small-scale and Large-scale Architecture

## Small-scale prototype

```text
CSV dataset
→ Streamlit web app
→ Pandas data validation and EDA
→ Scikit-learn ML model
→ SHAP explanation
→ Copilot translation layer
→ Recommendation rule matrix
→ Dashboard / controlled chat / report evidence
```

## Large-scale enterprise architecture

```text
CRM / business systems
→ cloud database or data warehouse
→ data processing pipeline
→ ML prediction API
→ explainability service
→ Copilot service
→ web dashboard / conversational interface
→ monitoring, logging, audit and governance layer
```

## Large-scale considerations

- role-based access control
- audit logs
- model versioning
- data governance
- privacy controls
- monitoring and drift detection
- explanation traceability
- human decision review
